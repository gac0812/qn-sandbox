# 08 — 安全规范

状态：Draft · 2026-10-24 · 安全条款为硬约束，等级高于编码风格 · 上位文件：guardrails README「Security Invariants」（逐条落实）

## 1. 威胁模型（先说清防谁）

| 资产 | 对手 | 边界 |
| --- | --- | --- |
| 宿主敏感文件（`~/.ssh`、`~/.aws`、浏览器 profile 等）与凭据 | 沙箱（受限进程环境）内运行的 Agent 代码，包括被提示词注入诱骗的合法 agent | 内核原语（Seatbelt/Landlock，不可逆）+ 默认拒绝 |
| 真实凭证（API key/OAuth/token） | 同上 | 凭证代答：明文只在宿主侧；沙箱内只有短时占位符/句柄 |
| 出站目标与数据外传 | 同上 | 网络默认拒绝 + 按 profile 的域名/L7 白名单（经代理） |
| MCP 服务器凭证 | 沙箱内 agent 及其配置文件 | MCP gateway：agent 配置只有 Handle，认证宿主侧代答 |
| 控制面（qnd/CLI） | 本机其他进程 | 本地 token 认证 + 最小权限 |
| 审计记录 | 事后抵赖/篡改 | native 决策以 nono 防篡改日志为源；qn 呈现副本保留来源。qn 自有 broker 事件另记宿主补充证据，不冒充 nono 防篡改记录（#105） |

**明示的非目标（P0/P1 威胁模型之外）**：宿主内核 0-day（进程级方案与宿主共内核，需独立内核的场景用 P2 强隔离 VM 模式）；拥有宿主管理员权限的攻击者；侧信道。此取舍须在用户文档中如实呈现。

## 2. 隔离基线（按平台）

| 平台 | 机制 | 关键要求（测试必须覆盖） |
| --- | --- | --- |
| macOS | nono（Seatbelt） | fs+网络默认拒绝；敏感路径默认阻断；限制不可逆、子进程继承 |
| Windows | qn-wsl 供给 WSL2 + nono（Landlock） | 同上；**内核 ≥6.7 才有 Landlock 网络限制**，供给链路负责探测/升级并在 doctor 中显示；不达标时明确降级告知（fs-only）而非静默 |
| P2 强隔离模式 | 独立 VM + guest 内 nono | 独立内核；面向合规场景；非默认 |

"显式放行白名单"是唯一授权方式：profile 声明 fs 范围、出站域名/L7 规则、凭证绑定；
禁止任何"默认放开工作目录全部权限"的便利开关。

## 3. 网络与文件系统策略

- **默认拒绝，自 P0 起**（guardrails 不变式）：fs 与网络出入站默认 deny；按 **profile** 显式放行。
- 放行只能经：nono 的 fs 白名单与网络代理（allowlist + L7 规则）；profile 变更留审计事件。
- 端口转发/入站：显式申请，默认仅本机回环；`--host 0.0.0.0` 需 `--danger-allow-lan` 且回显警告。

## 4. 凭证安全（产品核心承诺）

产品承诺：**沙箱内配置任何 Agent 应用或 MCP 服务均无需填写任何敏感信息**。
硬性不变式：**凭证明文绝不进入沙箱的文件系统、环境变量、进程参数或 Agent 上下文——无短期例外。**

- 真实凭证只在宿主侧（存放跟随 nono 的宿主机制）；禁止写入 qn 配置/状态/日志/审计呈现。
- 沙箱内允许存在的只有：短时**占位符 / broker 句柄**（phantom tokens，短生命周期、受限作用域、
  撤销即失效）与代理地址等非敏感配置。
- 凭证进入网络的方式是**宿主代答**：nono 代理按 (会话 × grant) 在出站认证字段上附加真实凭证。
- **禁止**任何形式的注入（env/argv/挂载文件/短时真凭证下发）；放宽 = 推翻 guardrails 不变式，
  必须走决策 issue + 三人确认 + guardrails 修订。
- 托管配置（MCP/Agent 配置）写入前必须经 `qn-broker::write_managed_config` 校验：出现明文即拒绝。
- 授权模型：grant 记录（会话 × 引用 × 作用域），revoke 立即断供；审计只记引用名与时间，**不记值**。
- 攻击演示（读密钥/越权出站/env 探测/revoke 断供）是安全回归，见 05 §1/§2。

### 4.1 M1 执行要求（#47，2026-10-24 已接受）

- 生产启动必须调用共享 process 层的 `env_clear`，然后仅加入经 profile 批准的环境项；
  只提供 env 黑名单或仅清理版本探测不构成 sandbox run 的验收。
- 受管 profile 的 HOME/config/state/cache 与用户配置隔离；禁止从未受控的 user default、pack hooks
  或外部 profile 间接扩大权限。真实凭证、宿主 provider 和控制面状态不在沙箱 fs 白名单内。
- capture 入口只接收 grant 句柄和引用，逐请求验证会话/作用域/到期/撤销状态；设置上游缓存 TTL=0。
  provider 明文响应只在宿主内交给 nono 代理，禁止进入普通进程 stdout/stderr 日志、Debug 或错误摘要。
- 托管配置采用封闭结构，只包含批准的句柄和代理端点；未知字段、任意 env/header、非受管目标和
  原始凭证在写入前拒绝。写入失败不能留下可被使用的半份配置。
- revoke 完成后发起的请求必须断供；已经在途的请求须明确记录处理/取消结果，不能声称追溯撤销。
- 审计保留证据来源与完整性。child stderr 可伪造，`why` 是策略查询；二者不等于已认证的历史拒绝日志。
  停止退出码、列表消失及普通测试全绿均不能代替真实进程清理和攻击 E2E 证据。

此处接受实现方向，未宣称生产路径已经实现；真实 provider、官方 profiles、macOS/WSL 攻击与撤销
验收仍按 05 执行。授权与技术依据见 [#47](https://github.com/gac0812/qn-sandbox/issues/47)。

### 4.2 Broker 补充审计（#105）

qn 自有 capture 授权与拒绝不在 nono 原生日志中，补充记录必须标记 source=broker，
只含固定事件、qn 会话 ID、序号与时间；不含请求路径、句柄、引用值或秘密。宿主负责创建
沙箱不可访问的私有文件、持久化目录项并保留查询入口。写入须经 write/flush/data sync
确认后才执行对应特权步骤；失败、取消、超时或容量耗尽后永久拒绝继续使用该日志。
日志 IO 不持 grant 锁，delivery-prepared 记录之后仍须最终授权检查；prepared 不代表已送达。
这不替代 nono 防篡改源，不声称补充文件抗宿主篡改。决定与重审条件见
[#105](https://github.com/gac0812/qn-sandbox/issues/105)，沿用 #14/#47 委托授权，未声称 B/C 个人审批。

## 5. 控制面安全

- qnd 只监听本机；启动时生成本地 token（`~/.qn/token`，0600），CLI/UI/SDK 自动携带。
- 以普通用户权限运行，不申请 root/管理员；WSL2/内核升级等特权操作引导用户手动确认。
- 所有 RPC 输入（路径、profile 名、命令参数）白名单校验；命令走参数数组，禁止 shell 拼接。
- 会话注册表损坏 → fail-closed（拒绝服务优于错误信任），`qn doctor --repair` 修复。

## 6. 供应链安全

- `cargo deny advisories` 阻断已知漏洞依赖；新依赖走五问（04 §2）。
- **nono 锁版本**：安装包校验（digest/signature）后落盘；升级独立 PR + 攻击演示回归（04 §6）。
- 官方 profiles 来自本仓库或受信 registry，带来源与版本；Sigstore attestation 能力跟随上游启用。
- GitHub Actions 锁定 commit SHA，不用浮动 tag。

## 7. 隐私与日志

- 日志与审计呈现不得包含：凭证值、phantom token、用户文件内容、宿主敏感路径清单。
- 遥测默认关闭（当前无此计划）。

## 8. 安全相关变更的额外流程

- 触及本文件任何机制的 PR（隔离、凭证、策略、认证、进程拼接）必须：标题加 `security:` 前缀 +
  正文引用威胁模型条目 + 附"逃逸路径分析"小节 + 攻击演示子集通过证据。
- 攻击演示放行 = P0 缺陷（05 §6），修复需决策 issue 复盘威胁模型是否更新。
- AI 不得以"性能/便利"为由放宽本文件条款；放宽 = 推翻不变式，走决策 issue。
