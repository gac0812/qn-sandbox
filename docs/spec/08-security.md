# 08 — 安全规范

状态：Draft · 2026-10-24 · 沙箱项目的安全条款是硬约束，等级高于编码风格

## 1. 威胁模型（先说清防谁）

| 资产 | 对手 | 边界 |
| --- | --- | --- |
| 宿主机文件/凭据/密钥 | 沙箱内运行的 Agent 代码（半可信/不可信） | VM/容器边界 + 显式挂载白名单 |
| 宿主 daemon（qnd）与 CLI | 恶意调用方（本机其他用户/进程） | API 认证 + 最小权限 |
| 长期凭证（API key / password / token） | 沙箱内运行的 Agent 应用及其加载的 MCP 服务 | 凭证代理：明文只存宿主 OS 凭证库；沙箱内仅凭证引用；授权可撤销可审计（§4） |
| 其他沙箱 | 沙箱内代码 | 每沙箱独立网络命名空间/独立 WSL 容器 |
| 镜像与状态文件 | 下载/导入来源 | 校验（digest）+ 导入沙箱化 |

明确非目标（M5 前）：防御"拥有宿主管理员权限的攻击者"、防御侧信道、防御 guest 内核 0-day。

## 2. 隔离基线（按平台，测试必须覆盖）

| 平台 | 隔离机制 | 关键要求 |
| --- | --- | --- |
| macOS (VZ) | 独立 VM，guest 仅通过 arcbox agents 通道通信 | 默认无共享目录；剪贴板/USB 不开启；网络默认经代理策略 |
| Windows (WSL2) | 每沙箱一个容器（独立 namespace + cgroup）于受管发行版内 | 容器以非 root 运行业务进程；`/mnt/*` 互操作挂载对沙箱容器不可见；镜像目录不挂进沙箱 |
| QEMU 兜底 | 独立 VM | 同 macOS 要求 |

"显式挂载白名单"是唯一的数据进出方式：`qn cp` / API 传输，或用户显式 `--mount <宿主路径>:<沙箱路径>:ro|rw`。
禁止任何"默认把工作目录挂进去"的便利开关。

## 3. 网络策略

- 默认策略 M4 前：**出站全通（记录），入站仅本机回环映射**。
- M4+：默认拒绝出站，白名单代理（复用 arcbox SOCKS5 代理能力）按沙箱配置放行；策略变更必须经过 `NetPolicy` port，driver 不得私自改网。
- 端口转发：显式申请、绑定 127.0.0.1 默认；`--host 0.0.0.0` 需 `--danger-allow-lan` 且命令行回显警告。

## 4. 凭证安全（ADR-0004 修订版，产品核心承诺）

产品承诺：**沙箱内配置任何 Agent 应用或 MCP 服务均无需填写任何敏感信息**。
硬性不变式（与仓库 guardrails README / Issue #1 对齐）：**凭证明文绝不进入沙箱的文件系统、
环境变量、进程参数或 Agent 上下文——没有"短期例外"**。落地规则：

- 长期凭证只保存在宿主 OS 凭证库（macOS Keychain / Windows Credential Manager）；
  禁止写入 qn 配置文件、状态文件、日志、镜像；`keyring` 是唯一访问入口（`qn-daemon` 独占）。
- 凭证进入网络的方式是**宿主代答**：qn-daemon 内的认证网关按 (沙箱 × grant) 在出站流量的
  认证字段上附加凭证；沙箱侧只有 `qn-agent` 提供的无凭证本地出口代理。
- 沙箱内允许出现的只有：**凭证引用**（`${qn:secret/<name>}`）与非敏感配置（代理地址等）；
  托管配置（MCP 配置等）中出现明文密钥即校验失败、拒绝写入。
- **禁止**以任何理由把凭证递进沙箱：环境变量注入、argv、挂载文件、短时 token 下发一律不允许；
  放宽本条 = 推翻 ADR-0004 + guardrails 不变式，走 ADR 流程。
- 授权模型：每次 grant 记录（沙箱 × 引用 × TTL），撤销立即断流；审计日志只记引用名与时间，**不记值**。
- 镜像与快照天然无凭证残留（凭证从未进入过沙箱）；网关侧明文仅存宿主内存，进程退出即消失。

## 5. 宿主端 API 安全

- daemon 只监听本机；认证用启动时生成的本地 token（`~/.qn/token`，0600），CLI/SDK 自动携带。
- daemon 以普通用户权限运行；**不申请 root/管理员**。需要特权的操作（WSL 安装、Hyper-V）通过引导用户手动执行或 UAC 弹窗，daemon 自身不提权。
- 所有 RPC 输入（路径、镜像名、命令参数）做白名单校验；guest 内命令拼接必须走参数数组，禁止 shell 字符串拼接（`sh -c "user_input"` 禁止）。
- 沙箱状态/注册表文件损坏视为不安全输入：fail-closed（拒绝服务优于错误信任）。

## 6. 供应链安全

- `cargo deny advisories`（RustSec）CI 阻断已知漏洞依赖。
- 依赖新增按 `04` 五问；`unsafe` 禁令见 02 §6。
- 镜像/根文件系统来源必须记录 digest，导入时校验；测试 fixture 镜像只来自本仓库构建脚本或官方源。
- GitHub Actions 使用 `actions/…` 锁定 commit SHA，不用浮动 tag。

## 7. 隐私与日志

- 日志不得包含：token、用户文件内容、宿主路径之外的个人信息；exec 输出在 `trace` 级以上默认截断。
- 遥测：默认关闭；若未来引入，opt-in 且明示数据范围（当前无此计划）。

## 8. 安全相关变更的额外流程

- 触及本文件任何机制的 PR（挂载、网络、认证、凭证代理、进程拼接）必须：在 PR 正文标注 `security:` 前缀 + 引用威胁模型条目 + 给出"逃逸路径分析"小节。
- 出现疑似逃逸/越权行为：P0（见 05 §6），修复需 ADR 复盘威胁模型是否要更新。
- AI 不得以"性能优化/便利"为由放宽本文件条款；放宽=推翻条款=必须走 ADR。
