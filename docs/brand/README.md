# qn sandbox · 品牌素材

<img src="logo-icon.svg" width="120" alt="qn sandbox logo">

**含义**：Agent 住在一间「关得住、但待着很舒服」的玻璃屋里。玻璃是内核强制的边界（看得见、碰不出去），陶土橙的小方块是正在干活的 Agent。

## 文件

| 文件 | 用途 |
| --- | --- |
| `logo-icon.svg` | 主图标（奶油底），README、文档、应用图标 |
| `logo-icon-dark.svg` | 深色底图标，深色界面与幻灯片 |
| `logo-mark.svg` | 无底图形，放在任意浅色背景上 |
| `logo-icon-small.svg` | 小尺寸优化版：线条更粗、去掉高光，用于 ≤ 48 px |
| `logo-lockup.svg` / `logo-lockup-dark.svg` | 横版字标（图形 + qn sandbox），文字已转为路径 |
| `logo-512.png` / `logo-1024.png` / `logo-dark-512.png` | 位图图标 |
| `favicon.ico`、`favicon-16/32/48.png`、`apple-touch-icon.png` | 网页图标（由小尺寸版导出） |
| `social-card.png` | 1280×640 社交分享图，可在仓库 Settings → Social preview 上传 |

## 颜色

| 名称 | 色值 | 用在 |
| --- | --- | --- |
| 陶土橙 | `#D97757` | Agent、强调色、字标中的 sandbox |
| 墨色 | `#2A1A14` | 描边、正文、深色背景 |
| 奶油底 | `#FFF4E8` | 图标底色、浅色背景 |
| 玻璃蓝 | `#D5EEF4` | 玻璃屋 |
| 钥匙金 | `#F2B84B` | 辅助色（凭证、成功提示） |
| 薄荷绿 | `#3E9B6F` | 辅助色（已隔离、通过） |

## 字体

字标使用 [Fredoka](https://github.com/google/fonts/tree/main/ofl/fredoka)（SIL OFL 1.1）："qn" 600 字重，"sandbox" 400 字重。SVG 中的文字已转为路径，无需安装字体。

## 使用约定

- 四周至少留出图标宽度 1/8 的空白；不要拉伸、旋转，也不要更换图形内的颜色。
- 小于 48 px 时使用 `logo-icon-small.svg` 或 favicon 系列。
- 图形与字标为本项目原创，不含第三方 Logo。
